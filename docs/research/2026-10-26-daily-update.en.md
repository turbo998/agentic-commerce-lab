- **Primary-Source Protocol Coverage (29 Zero-Overlap Upstream PRs, `PR-01..PR-16`)**:
  - `PR-01` (`x402-foundation/x402#3941`): Aligns `scheme_exact_svm.md` `SettlementResponse.payer` with code so it reports the buyer wallet's Base58 public address (SPL transfer authority at `transferIx.accounts[3]`) rather than the facilitator fee payer (`transactionMessage.feePayer` at `accountKeys[0]`).
  - `PR-02` (`x402-foundation/x402#3594`): Decouples `e2e/src/mechanisms.ts` from importing `@x402/cardano` prior to the build step by injecting `masumiEscrowAddress?: (network: string) => string`.
  - `PR-03` (`x402-foundation/x402#3573`): Caps Python `x402[svm]` at `solana>=0.36.0,<0.40` so `from x402.mechanisms.svm import KeypairSigner` is protected from `solana 0.40.0` removing `solana.rpc.api`.
  - `PR-04` (`x402-foundation/x402#3550`, `#3540`): Hardens `verify-package-exports.mjs` in release/publish workflows to fail closed (`process.exit(1)`) when `checkedCount === 0` (unless `VERIFY_EXPORTS_ALLOW_EMPTY=1`) or when any declared `exports` file is missing; plus `socseal-verify` `ML-DSA-87` mined block height (`height > 0`) verification.
  - `PR-05` (`a2aproject/a2a-python#1377`): Mounts REST tenant routes at `f'{path_prefix}/{{tenant}}'` instead of `/{tenant}{path_prefix}`, ensuring `/a2a/rest/my-tenant/message:send` matches and populates `context.tenant`.
  - `PR-06` (`a2aproject/a2a-python#1375`): Rejects non-dict JSON-RPC envelopes, envelopes missing both `result` and `error`, and non-int `error.code` with `A2AClientError`, while mapping known error codes (`-32001` $\to$ `TaskNotFoundError`) even when extra fields (`reason`) are present.
  - `PR-07` (`a2aproject/a2a-python#1286`, `#1277`, `#1274`, `#1273`): Cross-SDK `ES256` AgentCard signature interop vectors (`S0-001..S0-004` `MUST-ACCEPT`, `S0-REJECT-005` `MUST-REJECT`), `Content-Type: application/a2a+json` on REST responses, `ParseDict(..., ignore_unknown_fields=True)` with `google.rpc.ErrorInfo` on structural type errors, and `v0_3/proto_utils.py` field roundtripping.
  - `PR-08` (`stripe/stripe-cli#2155`, `#2143`, `#2141`): Blocks silent plugin auto-upgrades across major semver boundaries (`isMajorPluginUpgrade`), distinguishes missing OS/arch builds from nonexistent pinned versions (`explainPinnedVersionNotFound`), and passes all 5 macOS signing/notarization secrets to GoReleaser.
  - `PR-09` (`stripe/stripe-node#2895` & `stripe/stripe-go#2457`): Disposes discarded `fetch` response streams (`res.dispose?.()`) before retry, verifies webhook notifications asynchronously (`parseEventNotificationAsync`), and returns `errEmptyPageWithHasMore` on empty V1 list pages where `has_more=true` and `single=false`.
  - `PR-10` (`coinbase/agentkit#1510`, `#1508`, `#1504`): `x402Guard` pre-payment EIP-712 signed seller trust census (`pay` / `caution` / `avoid`) and `KeeperHub` mandatory pre-broadcast simulation (`simulate: true`) + `taskId` idempotent execution replay.
  - `PR-11..PR-12` (`modelcontextprotocol/python-sdk#3761`, `#3625`, `#3619`, `#3618`): Strict `time.time() < self._expiry` token boundary per RFC 7519 §4.1.4, non-integer `listen-1` stream probe request IDs, `httpx2.Timeout(30.0, read=300.0)` for custom clients, and shielded cancellation cleanup with `stateless_http=True` caveats.
  - `PR-13..PR-16` (MCP Go/Rust/Java/C# SDKs & Ext-Apps): `go-sdk#1293`/`#1292`/`#1290` (`2 * keepAliveInterval` `WriteDeadline` extension, SSE `AddReceivingCustomMethod` support, non-null empty slices in `complete`/`getPrompt`), `rust-sdk#1285` (`on_refresh_token_rejected` invoked only on `invalid_grant`), `java-sdk#1210`/`#1201` (per-subscription `notifierFactory` null guard and `LoggingMessageNotification.data` `.toString()` coercion), and `csharp-sdk#1878`/`#1874` & `ext-apps#720` (MCP Apps `2026-01-26` handshake, `Clone()` `MarshalResult` preservation, and SDK v2 role-peer isolation).
