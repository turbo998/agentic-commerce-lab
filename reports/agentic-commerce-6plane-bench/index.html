7 / 7 · MY TAKE GOOD FIT vs NOT FOR & READINESS

Adopt the 6-Plane Reference Architecture for Any Agent Touching Money or Order State

✅ Good Fit

• Multi-merchant Stripe Connect platforms routing Direct vs Destination + OBO Shared Payment Tokens.

• External PSPs integrating single-use SPT Resolve with Visa VIC, Mastercard Agent Pay, or Amex ACE Kit cryptograms.

• High-frequency API/tool monetization using MPP Tempo streaming sessions + Metronome token billing.

• Retailers ingesting UCP bulk catalog feeds (dev.ucp.common.feed) and compiling ACP ATDRP dispute evidence packs.

⛔ Not For

• Lifting-and-shifting classic 3-tier cookie/session Web apps and exposing internal CRUD endpoints directly as MCP tools.

• Calling SPT Resolve multiple times per checkout or storing decrypted RSA credential slices in plaintext logs.

• Running unaligned MPP sub-cent settlement schedules that forfeit fractional cents on session close.

• Assuming card gateways automatically forward structured AP2/ACP agent mandates to issuing banks (0/17 do today).
