3. Six High-Value Agentic Commerce Use Cases

Scenario 01 · D2C Retail & OTA

Frictionless Shopping Agent Checkout

Stack: Web Bot Auth + Markdown for Agents + Visa TAP / Mastercard Agent Pay

Outcome: Verified agents browse clean Markdown catalogs freely, while checkout mutations enforce dual cryptographic agent + consumer card-token anchors.

Scenario 02 · Publishers & Research Data

Pay-Per-Crawl Data & Content Monetization

Stack: AI Crawl Control + Pay Per Crawl + x402 + NET Dollar

Outcome: Converts unauthorized scraping into high-margin micro-revenue via native HTTP 402 settlement with Cloudflare acting as Merchant of Record.

Scenario 03 · Vertical SaaS & APIs

Paid Remote MCP Tool Marketplace

Stack: Stateless MCP (2026-07-28) + withX402 (paidTool) / MPP (mppx)

Outcome: External agents invoke tariff, logistics, or credit-scoring MCP tools on demand without human signups or monthly SaaS subscriptions.

Scenario 04 · Enterprise Procurement

Autonomous B2B Tail-Spend with Sub-Wallets

Stack: Cloudflare Wallets (Virtual Wallets) + Workflows + AI Gateway

Outcome: Finance provisions departmental *.cloudflare.pay wallets enforcing per-tx caps, daily budgets, and approved vendor allowlists.

Scenario 05 · Travel & Multi-Merchant Concierge

Cross-Merchant Negotiation & Split-Cart Sagas

Stack: Agents SDK + Durable Objects SQLite + Workflows + Cloudflare OS

Outcome: Dedicated per-agent SQLite stores quote locks while Workflows coordinate atomic holds/compensations inside Gatekeeper sandboxes.

Scenario 06 · Legacy Enterprise Storefronts

7-Day Zero-Refactor Agent Readiness

Stack: Markdown for Agents + Agent Visibility Template + Edge Stateless MCP

Outcome: Upgrades legacy storefronts with JSON-LD, /llms.txt, and Markdown catalog views purely at the CDN edge without touching backend ERP code.
