## 2. 2026-10-23 Primary-Source Protocol & Repository Audit Findings (Stage 170)

### 2.1 x402 Foundation (`x402-foundation/x402`, `main` Advanced to `79263af` + PR `#3910`)
1. **XRP Ledger Native Payment Channel `upto` Scheme Specification (commit `2b06a54` / PR `#3023`: `specs/schemes/upto/scheme_upto_xrpl.md`)**:
   - **Canonical Numeric CAIP-2 Network Identifiers Only**: Accepts only `xrpl:0` (Mainnet), `xrpl:1` (Testnet), and `xrpl:2` (Devnet), rejecting non-canonical aliases like `xrpl:mainnet` (`unsupported_network`); V1 supports native `asset: "XRP"` in integer drops ($1\text{ XRP} = 10^6\text{ drops}$) with `extra.areFeesSponsored == false`.
   - **Off-Ledger `CLM\0` Claim Signature & `/verify` Preconditions**: Signs `'CLM\0'` (`0x434C4D00`) + 32-byte `channelId` + 8-byte big-endian `uint64(maxAmount)` with canonical low-`s`. `/verify` rejects `settlementTransaction` (`invalid_upto_xrpl_payload_unexpected_settlement_transaction`), requires a fresh channel (`Balance == "0"`, `Expiration` unset, `Amount >= maxAmount`), and enforces a **20-second landing margin** (`CancelAfter >= close_time + maxTimeoutSeconds + 20` and `SettleDelay >= max(maxTimeoutSeconds + 20, minSettleDelay)`).
   - **`/settle` Ceiling Substitution, Bare `tfClose` on Zero Delta & `(network, channelId)` Single-Flight Mutex**: Substitutes `payload.maxAmount` for `requirements.amount` in Rules 1 & 4; when `settleAmount == 0` or `Balance >= settleAmount`, a channel-closing `PaymentChannelClaim` with `tfClose` (`0x00010000`) **MUST omit `Balance`, `Amount`, `Signature`, and `PublicKey`**; concurrent settlements on the same `(network, channelId)` are rejected with `upto_xrpl_channel_settlement_in_progress`.
2. **Method-Less Wildcard Route (`* /path`) `OPTIONS` Preflight Bypass & Browser CORS Contract (commit `3bd3c1d` `#3738`, commit `58a5d7d` `#3809`)**:
   - Skips `OPTIONS` preflight requests on method-less wildcard routes across TS, Python, and Go resource servers instead of returning HTTP `402`, and documents `Access-Control-Allow-Headers: PAYMENT-SIGNATURE, Content-Type` and `Access-Control-Expose-Headers: PAYMENT-REQUIRED, PAYMENT-RESPONSE` in `specs/transports-v2/http.md`.
3. **Batch Refund Receipt Fail-Closed Check, EVM Gas Sponsoring RPC Requirement, Paywall HTML XSS Escaping & Self-Payment Block (commits `470419d` `#3096`, `b5ee357` `#3459`, `9c50903` `#3889`, `a9772e5` `#3855`, PR `#3910`)**:
   - Fails closed when a batch refund receipt emits no `Refunded` amount (`#3096`), requires `readContract` or `rpcUrl` when registering EVM gas sponsoring (`#3459`/`#3889`), escapes `</script>`, `<`, `>`, `&`, and quotes in paywall HTML config injection (`#3855`), and blocks `payer == payTo` wash self-payments (`invalid_self_payment`, PR `#3910`).

## 3. Dialectical Architecture Analysis: AI-Native Workload Design vs. Cloud Classic 3-Tier / Well-Architected

| Dimension | Classic 3-Tier Web / Cloud WAF Assumption | Agentic Commerce AI-Native Deterministic Improvement (Stage 170) |
|---|---|---|
| **Payment Channel Landing Margin & CORS Preflight Isolation** | Synchronous DB debit has no consensus clock drift; wildcard auth middleware blocks all HTTP verbs including `OPTIONS` | Enforce `/verify` `settlementTransaction` prohibition, `Balance == 0`, `20s` XRPL landing margin on `CancelAfter`/`SettleDelay`, bare `tfClose` on zero delta, and `(network, channelId)` mutex (x402 `#3023`); bypass `OPTIONS` preflight on `* /path` routes (`#3738`/`#3809`); block `payer == payTo` wash self-payment (`#3910`) |
| **Checkout Lifecycle Regression & Zero-Due Subscription Schedules** | Checkout state only moves forward; subscription schedules are summed into cart checkout totals | Explicitly allow `ready_for_complete -> incomplete | requires_escalation` (`#672` `5410813`), exclude future `schedules[]` from checkout `totals` (`#890`), and bind signed REST responses to `@method`/`@target-uri` (`#699`) |
| **MCP Proxy Safety Annotations & Immediate JSON-RPC Error Synthesis** | Reverse proxies strip tool metadata and drop upstream error frames on stdio bridges | Preserve `destructiveHint`/`readOnlyHint` via `registerTool` (`#584`), synthesize immediate JSON-RPC error responses on request forwarding failures (`#542`), and enforce `SEP-3415` cursor truncation & Standard Webhooks signatures (`#3415`) |
| **Benchmark Denominator Integrity & Zero Internal Key Leakage** | Malformed tool-call JSON is treated as infra error and excluded from averages; test prompts may include DB keys | Score `ToolCallArgumentsError` and `EmptyResponseError` as `AGENT_ERROR` (`0.0` in denominator, `#674`) and strip internal `user_id` keys from user prompts (`#677`) |
