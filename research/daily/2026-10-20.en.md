## 2. Primary-Source Protocol & Repository Audit Findings (Stage 54)

### 2.1 Universal Commerce Protocol (`Universal-Commerce-Protocol/ucp`)
1. **PR `#982` (`fix(docs): restore bundled schema type links for ucp-schema 2.0.0 (#887)`, updated `2026-10-20`)**:
   - **Root Cause**: Starting with `ucp-schema 2.0.0` (`ucp-schema#66`), `ucp-schema resolve --bundle` strips non-root `$id` and `$schema` metadata from inlined schema definitions. Because `_restore_fragment_refs` previously only restored top-level `#/$defs/...` fragment refs, over 400 specification fields degraded to unlinked `object` or `Array[object]`. Additionally, `_resolve_schema` did not normalize `schema_path` via `Path(schema_path).resolve()`, allowing duplicate cache keys for relative vs. absolute paths.
   - **Architectural Implication**: AI-Native schema bundlers and MCP tool compilers must walk the unbundled source schema alongside the bundled schema (`_resolve_raw_ref` + `_restore_fragment_refs`) across properties, array `items`, `items.allOf` branches, and forwarded `#/$defs/...` aliases, while canonicalizing schema cache keys.
2. **PR `#962` (`feat(catalog): add optional seller logo`)**:
   - **Normative Semantics**: Adds optional `seller.logo` referencing shared `common/types/media.json` (`type: "image"`, `https://` `url`, and accessible `alt_text`) to `shopping/types/variant.json`.
   - **Security & Authority Boundary**: `seller.logo` identifies the display seller for a variant (not the manufacturer) and **does not establish a binding between that seller and a business discovery profile (`/.well-known/ucp`)**. Platforms MUST tolerate absent `seller` or `seller.logo` (`seller.name`-only) and MUST NOT treat `seller.logo` as cryptographic merchant authority.

### 2.2 Agentic Commerce Protocol (`agentic-commerce-protocol/agentic-commerce-protocol`)
1. **PR `#310` (`Detect JSON Schema and OpenAPI property drift`) & PRs `#290`, `#284`, `#275`**:
   - **Dual-Artifact Property Drift (`#310`)**: ACP publishes both JSON Schema (`$defs`) and OpenAPI 3.1 (`components.schemas`) for each version. Because OpenAPI sets `additionalProperties: false`, any property present in one artifact and absent in the other causes deterministic cross-SDK rejection. PR `#310` adds bidirectional property-set comparison, enumerates **23 pre-existing mismatches** in `scripts/known-property-drift.txt`, and fails validation both on new unlisted drift and on stale entries after reconciliation.
   - **`allOf` + `additionalProperties: false` Sibling Starvation Trap (`#290`, `#275`)**: In JSON Schema Draft 2020-12 / OpenAPI 3.1, `additionalProperties: false` on a base schema (`CheckoutSessionBase` in `#290` or `DelegateAuthenticationSessionBase` in `#275`) only recognizes properties declared inside that *same* schema object—not properties contributed by sibling `allOf` branches (`order` on `CheckoutSessionWithOrder` or `authentication_result` on `DelegateAuthenticationSessionWithResult`), causing valid responses to fail validation against their own specification!
   - **OpenAPI `PaymentHandler.display_order` Mis-Indentation (`#284`)**: `display_order` was indented as a sibling of `properties:` rather than inside `properties:` in `openapi.agentic_checkout.yaml`, causing `additionalProperties: false` to reject any `PaymentHandler` setting `display_order`.

### 2.3 Google AP2 (`google-agentic-commerce/AP2`) & Personal Agent Protocol (`Poppy v0.2`)
1. **AP2 PR `#369` (`test(ap2): add mandate conformance corpus and reference verifier`, updated `2026-10-20`) & `poc_aud_not_enforced.py` Audience Bypass Vulnerability**:
   - **Cross-Language Conformance Gap**: Prior to PR `#369`, only the Python SDK could sign/verify AP2 mandates (the Go sample hardcoded `FakeJWT = "******"`). PR `#369` introduces byte-level signed vectors (`USD` and non-USD `BRL`) and negative forgery vectors.
   - **Critical `kb+sd-jwt+kb` Audience Bypass (`poc_aud_not_enforced.py`)**: `kb_sd_jwt.verify` only enforced `expected_aud` and `expected_nonce` when `typ in TYP_TERMINAL` (`['kb+sd-jwt', 'kb-sd-jwt']`). Whenever a payload includes `cnf`, the AP2 SDK emits `typ="kb+sd-jwt+kb"` (`TYP_INTERMEDIATE`), causing `verify_chain` to silently skip `expected_aud` verification and accept an attacker-bound delegation hop (`aud="https://attacker.example/ap2"`, `VERDICT: DEFECT CONFIRMED`).
2. **AP2 PRs `#385` / `#383` (`cnf.jwk` JSON-Mode Serialization) & PR `#384` (`verify_receipt` Null Callback Guard)**:
   - `ParsedToken.cnf_jwk` called `model_dump(exclude_none=True)` without `mode="json"`, leaving `use="sig"` as a Python `Enum` (`Use.sig`) and causing `jwcrypto` to fail with `InvalidJWSSignature` (`#385`/`#383`).
   - `ReceiptClient.verify_receipt` called `has_reference_in_store_cb(receipt_reference)` unconditionally even when `has_reference_in_store_cb=None`, raising `TypeError` (`#384`).
3. **Poppy `v0.2` Commit `39b35bd` (`Make examples and guides match the spec (#71)`)**:
   - Clarifies §4.3: Every request to the token endpoint and every request carrying a Session Token MUST carry an `ES256` DPoP proof with $\ge 128$-bit `jti` entropy (except requests for an MCP Server Bearer token, §4.9 revocation, and §4.6 device authorization), and API write requests MUST include `Idempotency-Key`.

### 2.4 Sierra $\tau$-bench `2.0.0` (`#642`) & Visa Trusted Agent Protocol `x402` (`#11`)
1. **Sierra `sierra-research/tau2-bench` `2.0.0` (`989d328`, merged `2026-10-20`)**:
   - Launches **$\tau$-i18n across 6 languages** (`en`, `es`, `pt`, `hi`, `zh`, `ko`) and 5 pinned manifests (`voice-v2` 900 calls, `text-v1` 900 calls, `voice-v2-banking` 582 calls, `voice-v2-entity` 1,200 calls, `voice-v1`); scores are not comparable with `1.x` (`v1.0.1`).
   - Introduces the **$\tau$-entity Outbound `intake` Domain (`data/tau2/domains/intake/agent_directed_policy.md` & `ENTITY_PROVENANCE.md`)** with six deterministic invariants:
     1. **Consent-Before-Collection**: State the call purpose (naming the record owner and client organization) and obtain explicit consent before asking for any missing form field;
     2. **Scoped Minimization**: Collect *only* fields listed in `callback_order.missing_fields` and never invent or import external values;
     3. **Silent `log_capture` Before Submit**: Never narrate internal tools to the person, and log every captured field via `log_capture` prior to submission;
     4. **Check-Digit & Format Verification**: Enforce VIN check digits, `mod-97` member IDs (`int(digits) % 97 == 1`), `YYYY-MM-DD` dates, and `H:MM AM/PM` times;
     5. **Single `submit_fields` & Zero Submission on Early Hangup**: Submit all fields in exactly one `submit_fields` call, and submit nothing if the person hangs up early;
     6. **Turn Separation Between `submit_fields` and `end_call`**: Never invoke `submit_fields` and `end_call` in the same turn.
2. **Visa Trusted Agent Protocol PR `#11` (`Feat/x402 implementation`)**:
   - Integrates machine-to-machine `x402` USDC checkout on Solana (`solana:EtWTRABZaYq6iMfeYKouRu166VU2xqa1`) and Base Sepolia (`eip155:84532`): Mode A (no `PAYMENT-SIGNATURE` header) returns HTTP `402` with `PAYMENT-REQUIRED`; Mode B settles on-chain via the facilitator, verifies `subtotal + tax + shipping == total_amount`, and returns `PAYMENT-RESPONSE`.

## 3. Dialectical Architecture Comparison: AI-Native vs. Cloud 3-Tier Web / Well-Architected

| Dimension | Cloud 3-Tier Web / WAF Assumption | Agentic Commerce AI-Native Guardrail (Stage 54) |
|---|---|---|
| **Dual-Spec Contract Evolution** | Hand-edited OpenAPI tolerated by lenient browser UI | Deterministic JSON Schema ↔ OpenAPI drift detection (`ACP #310`), elimination of `allOf` + `additionalProperties: false` sibling starvation (`#290`/`#275`), and bundled `$ref` restoration (`UCP #982`) |
| **Display Media vs. Discovery Authority** | Seller logo in UI implies verified merchant identity | Strict non-authority boundary on `seller.logo` (`UCP #962`); authority requires cryptographic `/.well-known/ucp` verification |
| **Multi-Hop Delegation Verification** | Single-hop JWT check trusting SDK `typ` branching | Mandatory terminal `expected_aud`/`expected_nonce` verification across `kb+sd-jwt+kb` (`AP2 #369` fix) and JSON-mode `cnf.jwk` serialization (`#385`/`#383`) |
| **Outbound Voice/Entity Capture State Machine** | Freeform conversational LLM batching tool calls at hangup | Deterministic $\tau$-bench 2.0.0 `intake` gate: explicit consent $\rightarrow$ scoped fields + `mod-97`/ISO format $\rightarrow$ `log_capture` $\rightarrow$ single `submit_fields` on a separate turn before `end_call` |
