## 2. 2026-10-27 一手协议与上游仓库新增证据深度审计

### 2.1 Sierra Poppy / Personal Agent Protocol Draft 0.3：登录前 `auth.scope_hints` 不可逆操作分级与 Validator Token Exchange 校验（`#103`、`#106`、`#108`、`#76`）
- **核心变更**：
  1. **OAuth 登录前 Scope 影响度提示（`#103` `Add scope hints`）**：商家在 `.well-known` / 发现元数据 `auth.scope_hints` 中针对每个 OAuth scope 声明两项正交属性：`changes`（`"none"` | `"reversible"` | `"irreversible"`）与 `personal_data`（`true` | `false`），对齐 MCP Tool Annotations 的操作后果语义。Personal Agent 可在发起 OAuth 登录重定向前识别出包含 `"irreversible"`（如扣款、销户、不可撤回退单）或 `personal_data: true` 的高危 scope，强制在签入前拦截并征得用户显式同意（User Go-Ahead）。
  2. **Validator 强制核验 RFC 8693 Token Exchange、`invalid_target` 与 `/feedback` 端点（`#108`）**：Poppy 官方合规验证器新增对 Token Exchange 跨受众降权、非法目标资源返回标准 `invalid_target` 错误码，以及交互后 `/feedback` 端点的自动化探测。

### 2.2 Universal Commerce Protocol (UCP)：`ucp-schema 2.0.0` 跨文件 `$ref` 递归解析与无标题联合分支标记（`#887` / `#982`）
- **核心变更**：
  - `Universal-Commerce-Protocol/ucp#982`（`2026-10-27T12:45:34Z` 合并）修复 `ucp-schema 2.0.0` 捆绑与非捆绑 JSON Schema 的递归类型链接解析：遍历 `properties`、`items`、`additionalProperties`、`allOf`、`oneOf`、`anyOf`，并在 `_restore_fragment_refs` 中为无标题 `#/$defs/<name>` 分支注入 `x-ucp-def-name` 回退标识（如将 `Catalog Lookup with Loyalty` 精确渲染为 `Lookup Response, Get Product Response`），防止忠诚度目录查询在联合类型折叠时丢失分支契约。

### 2.3 Sierra $\tau$-bench 2.0：语音保真度评委输出长度封顶与轨迹惰性可视化（`#691`、`#690`、`#693`）
- **核心变更**：
  - `sierra-research/tau2-bench#691`（`2026-10-27T09:40:33Z` 合并）收紧语音保真度（Speech-Fidelity）LLM Judge 的回复格式约束并设置硬性输出 Token 上限（Output Cap），消除评测裁判长篇发散导致的解析截断与评测抖动；`#690`（`2026-10-27T10:29:31Z` 合并）引入按基准分片的惰性加载轨迹可视化器。

### 2.4 Stripe AI SDK & Tempo MPP：同步失败技能缓存保护、本地代理保留远端 MCP 注解与无事件循环同步工具执行（`stripe/ai#586`、`#584`、`#581`，`tempoxyz/mpp#1128`、`#1127`）
- **核心变更**：
  - `stripe/ai#586` 在技能同步下载失败时保留本地已有 Skills 缓存而非清空目录（Fail-Safe Cache Preservation）；
  - `stripe/ai#584` 在 `@stripe/mcp` 本地代理转发时完整保留远端 MCP 工具的 `annotations` 元数据（如 `destructiveHint`、`idempotentHint`）；
  - `stripe/ai#581` 修复 Python 端 LangChain / CrewAI 在工作线程无活跃 asyncio 事件循环时调用同步工具抛出异常的缺陷。

## 3. 辩证架构思考：Agentic Commerce AI-Native 六平面架构 vs. 云厂商经典三层 Web 架构（Well-Architected）

| 架构维度 | 云厂商经典三层 Web 架构（Presentation → Stateless App → DB） | Agentic Commerce AI-Native 六平面确定性架构（Stage 618–621） |
|---|---|---|
| **授权同意时机（Consent Timing）** | 假定人类用户在浏览器亲眼阅读 OAuth 授权页文字，将所有 Scope 视为粗粒度读写权限 | **登录前后果分级门控（Pre-Sign-In Consequence Gating）**：消费 Poppy `auth.scope_hints`（`changes: irreversible`, `personal_data: true`）与 `@stripe/mcp` 远端工具注解，在 OAuth 握手前触发确定性人类确认门禁 |
| **凭证作用域与到期淘汰** | 长期静态 `sk_live_*` 存放于环境变量，跨微服务共享全账户权限 | **硬截止期与受众降权（Hard Sunset & Token Exchange）**：强制拦截 `2026-10-31` / `2026-11-30` 后的遗留 Stripe API 密钥，要求 `rk_live_*` 委托密钥或 OAuth 2.1 + RFC 8693 `invalid_target` 边界校验 |
| **多模态 Schema 演进与技能同步** | 依赖手工维护 DTO，配置中心拉取失败时可能导致空路由或静默降级 | **捆绑 Schema 递归校验与技能缓存防清空**：对齐 UCP `#982` `allOf`/`oneOf` 分支契约校验，并在远端技能同步异常时保留最后已知完好快照（`stripe/ai#586`） |
