## 3. Dialectical Architecture Analysis: Agentic Commerce AI-Native Six-Plane Architecture vs. Cloud Well-Architected 3-Tier Web Apps

| Architectural Dimension | Classic Cloud 3-Tier Web Architecture (Presentation → Stateless App → DB) | Agentic Commerce AI-Native Six-Plane Deterministic Architecture (Stages 618–621) |
|---|---|---|
| **Consent & Authorization Timing** | Assumes a human reads HTML OAuth consent screens in a browser; treats OAuth scopes as coarse read/write strings | **Pre-Sign-In Consequence Gating**: Evaluates Poppy `auth.scope_hints` (`changes: "irreversible"`, `personal_data: true`) and `@stripe/mcp` tool annotations **before** OAuth sign-in, escalating irreversible scopes to human confirmation |
| **Credential Lifecycle & Scoping** | Long-lived static `sk_live_*` keys stored in environment variables shared across stateless workers | **Hard Sunset & Audience Down-Scoping**: Blocks legacy Stripe API keys past the `2026-10-31` / `2026-11-30` cutoffs, requiring `rk_live_*` Agent keys or OAuth 2.1 + RFC 8693 Token Exchange with strict `invalid_target` validation |
| **Schema Evolution & Skill Sync Resilience** | Hand-written DTOs and brittle config syncs that wipe local caches on transient network errors | **Recursive Bundled Schema Verification & Fail-Safe Skill Cache**: Enforces UCP `#982` `allOf`/`oneOf` union contracts and preserves last-known-good local skills when sync downloads fail (`stripe/ai#586`) |
