## 2. 2026-10-22 Primary-Source Protocol & Repository Audit Findings (Stage 168)

### 2.1 x402 Foundation (`x402-foundation/x402`, 25+ Commits Merged to `main` Through `7617ece`)
1. **Strict V2 CAIP-2 Network Regex & V1 Payload 402 Rejection (commit `3ca54cb` `#3285`, commit `6c379c4` `#3715`)**:
   - `NetworkSchemaV2` in `@x402/core` enforces the strict CAIP-2 regex `^[-a-z0-9]{3,8}:[-_a-zA-Z0-9]{1,32}$` (rejecting uppercase namespaces, dots in references, or out-of-range lengths).
   - `x402HTTPResourceServer.processHTTPRequest` rejects V1 payloads sent in `PAYMENT-SIGNATURE` with HTTP `402` (re-issuing `Payment-Required`) instead of crashing with HTTP `500`.
2. **Control-Plane (`1 MiB`) / Bazaar Discovery (`4 MiB`) Response Body Caps & `extensions` Shallow Copy (commit `76f2f28` `#3400`, commit `bc31d3e` `#3826`, commit `b70da0d` `#3567`)**:
   - `readBoundedResponseText` caps Facilitator `verify`/`settle`/`supported` bodies at `1 MiB` (`1,048,576` bytes) and Bazaar discovery responses at `4 MiB` (`4,194,304` bytes), cancelling the underlying stream and raising `ResponseBodyTooLargeError` on overflow.
   - `createPaymentRequiredResponse` shallow-copies `extensions` (`{ ...extensions }`) so 402 response enrichment (`offer-receipt`) never mutates route declarations needed by `enrichSettlementResponse` (`includeTxHash: true`).
   - Bazaar `extractDiscoveryInfo` keeps the advertised HTTP method aligned with the declared input shape (`bodyType` $\rightarrow$ `POST`/`PUT`/`PATCH`; query $\rightarrow$ `GET`/`HEAD`/`DELETE`).
3. **Cardano Raw-CBOR Byte-Preserving Broadcast, Stellar `TRY_AGAIN_LATER` Retryability & EVM/Upto `failed_to_verify_signature` Parity (commit `d8e1e7b` `#3674`, commit `332f65d` `#3125`/`#3293`, commit `7438976` `#3690`, PR `#3886`/`#3887`)**:
   - `@x402/cardano` facilitator broadcasts the client's signed transaction byte-for-byte via raw-CBOR endpoints (Blockfrost `/tx/submit`, Koios `/submittx`), preventing CBOR re-serialization from adding Conway tag `258` and invalidating `vkey` witnesses (`MissingVKeyWitnessesUTXOW`).
   - `@x402/stellar` classifies `TRY_AGAIN_LATER` as retryable (`settle_exact_stellar_transaction_submission_retryable`) while keeping `ERROR` terminal.
   - `@x402/evm` (`exact` and `upto` in PR `#3886`) reports failed payer `eth_getCode`/signature lookups as `invalid_*_evm_failed_to_verify_signature` rather than bad signatures.
4. **Python `x402[mcp]` `<2` Bound, Client Retry Header Hygiene & `@x402/axios` Cookie Array Preservation (commit `0ff11aa` `#3425`, commit `1e7de94` `#3717`, commit `202ba81` `#3728`, PR `#3575`, commit `732c181` `#3795`)**:
   - Pins Python `x402[mcp]` to `mcp>=1.0.0,<2`; strips response-only `Access-Control-Expose-Headers` from Python payment retry requests; preserves `Cookie` arrays for semicolon serialization and runs `onPaymentResponse` before rejecting paid HTTP 4xx/5xx responses in `@x402/axios`; caps Go MCP corrective retry timeout with `MaxRequestTimeout`.

## 3. Dialectical Architecture Analysis: AI-Native Workload Design vs. Cloud Classic 3-Tier / Well-Architected

| Dimension | Classic 3-Tier Web / Cloud WAF Assumption | Agentic Commerce AI-Native Deterministic Improvement (Stage 168) |
|---|---|---|
| **Multi-Rail Control-Plane Bounds & Byte Preservation** | Assumes upstream HTTP responses fit in memory, CBOR/JSON re-serialization is lossless, and config dicts can be mutated in place | Enforce `1 MiB` control-plane / `4 MiB` discovery streaming body caps (x402 `#3400`), shallow-copy `extensions` on 402 enrichment (`#3826`), broadcast Cardano signed transactions as raw CBOR bytes (`#3674`), and separate retryable Stellar `TRY_AGAIN_LATER` & EVM RPC lookup errors from bad signatures (`#3293`/`#3690`/`#3886`) |
| **Cart-to-Checkout Capability Negotiation Gate** | Backend silently ignores unrecognized optional fields and falls back to inline request parameters | When `cart_id` is supplied without negotiated `dev.ucp.shopping.cart` capability, the Business **MUST reject** the request and **MUST NOT** silently fall back to `line_items` (UCP `#940` `2bbae24`) |
| **Recurring Delegated Payment Tokens (Recurring SPT)** | Subscriptions attach `setup_future_usage="off_session"` on `PaymentIntent` to vault the card for merchant-initiated charges | Recurring SPTs reuse the scoped token via `usage_limits.recurring_interval`; passing `setup_future_usage` on any SPT `PaymentIntent` is deterministically rejected to prevent escalating a scoped grant into an un-scoped vaulted credential (Stripe `stripe-spt` `2026-10-22`) |
| **Full-Duplex Voice Agent Stream Gating & Cross-OS Reproducibility** | WebSocket audio chunks are queued FIFO; OS line endings do not affect evaluation integrity | Gate playback strictly to `[assistant_started_speaking, assistant_finished_speaking]` so inter-utterance silence frames during orchestrator stalls do not lag subsequent turns ($\tau$-bench `#670`), enforce LF byte digests (`#671`), and reject same-SKU exchanges and empty `mmsc_url` (`#667`/`#666`) |
