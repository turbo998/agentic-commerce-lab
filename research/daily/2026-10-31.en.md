## 6. Architecture impact and open items

1. **Execution-authority separation remains strict:** claim visibility is not external-action authority.
2. **Monitoring signal quality improved:** layered “noise filtering + selected facts” now covers both seller and connect SPT views.
3. **Cross-source validation now includes a gate:** `cross_source_checks` verifies seller/connect parity, and `mismatch` now fails the monitor run explicitly.
4. **Connect semantic integrity is now gated:** missing required Connect markers triggers `mismatch` and blocks monitor success.
5. **Parser-version parity is now gated:** seller/connect selected-facts parser drift triggers `mismatch` and blocks monitor success.
6. **Cross-source gate health is now summarized:** `cross_source_summary` exposes stable counters and a blocking flag for automation and daily reporting.
7. **Run-level blocking state is now summarized:** `gate_health` combines fetch failures, facts-parse failures, and mismatch gates into one deterministic blocking signal.
8. **Blocking reasons are now directly consumable:** `gate_health.blocking_reasons` emits fixed-order blocking classes, reducing downstream reason-inference logic.
9. **Check status is now O(1) readable:** `cross_source_statuses` provides a stable index and reduces consumer parsing divergence.
10. **Blocking routing can now consume grouped IDs directly:** `cross_source_partitions` groups check IDs by status and removes repeated downstream grouping logic.
11. **Run-level blocking checks are directly readable:** `gate_health.cross_source_blocking_checks` removes extra joins for blocker routing.
12. **Report contract is now explicitly versioned:** `schema_version` provides a stable compatibility anchor for consumer parsers.
13. **MCP deadline simulation is now source-provenance-aware:** `lab.mcp_migration` can optionally consume daily `stripe-mcp` selected facts and emits `deadline_source/deadline_parser_version` for auditable boundary changes.
14. **Poppy publication gate unchanged:** production implementation remains anchored to published `0.2` until `0.3` is formally published.
